markdown## サービス概要
独学エンジニアが学習ログを継続・公開できるSNS型アプリ。
「記録が続かない・仲間がいない」課題を解決するために自作。
## 進捗
4月第1週
現状のプロジェクトの進捗メモの記入欄と良いねボタンの設置完了
クラウドやローカルのDBと連携していないためページ更新で全て元に戻るが
おおむねフロントエンドはもう少し工夫したら完成。

## ターゲット
プログラミング独学中の未経験エンジニア志望（≒ 過去の自分）

## 機能一覧
| 機能 | 説明 | 実装状況 |
|---|---|---|
| 学習ログ投稿 | 管理者のみ投稿・編集・削除 | ✅ |
| いいね機能 | 全ユーザーが押せる | ✅ |
| コメント機能→質問投稿に変更 | 全ユーザーが投稿可 | 🔧 実装中 |

## 技術スタック
- Frontend: Next.js 14 (App Router)
- Backend: Next.js API Routes
- ORM: Prisma
- DB: PostgreSQL (Render)
- Deploy: Render
→renderDBが無料枠の期限切れのため、supabaseへとDBを移行しました。
